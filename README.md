# Trophy Dilution Forecaster v10

Forecasts each GTA VI trophy's Exophase earn rate one week after launch, as five quantiles per trophy.

[![reward](https://make.fun/badge/gta6-trophy-rarity-forecast-01/rohitchanuwu69-bot/gta6-trophy-rarity-forecast-01-v10/reward.svg)](https://make.fun/bounty/gta6-trophy-rarity-forecast-01)

Bounty: [Forecast how many GTA VI players earn each trophy in week one](https://make.fun/bounty/gta6-trophy-rarity-forecast-01)

Entry: `main.py` (Python 3.13, standard library only). Run it with `MAKEFUN_INPUT_DIR` / `MAKEFUN_OUTPUT_DIR` set; it reads every `*.in` case and writes one `*.out` per case.
